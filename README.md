# LG전자 VS본부 생산 데이터 분석 - 불량 예측 AI 모델

## 과제 개요
LG전자 VS본부 Sub Assembly Line의 생산 공정 데이터를 활용하여 불량 발생 여부를 예측하는 AI 분류 모델 개발

## 배경
차량용 디스플레이(Cluster + CID) 생산 공정에서 발생하는 다양한 불량(기포, Crack, Misalignment 등)을 사전에 예측하고, 데이터 기반 품질 관리 체계 구축을 목표로 함

## 생산 프로세스
### Sub Assembly Line 주요 공정
1. **Resin 도포 & 반경화** - 외측/내측 도포(Dam, Fill), UV 경화
2. **합착** - Glass + Display 결합
3. **탈포** - 진공 챔버에서 미세 기포 제거
4. **완전 경화** - UV 경화 2차
5. **검사**

## 데이터
- **X (입력)**: 각 공정별 측정 및 설비 파라미터
  - Resin 도포: 토출 좌표/속도/시간/양, UV 경화 속도/시간 등
  - 합착: Glass 이동 좌표/속도, 합착 Gap, 공정 온도/습도 등
  - 탈포: 탈포 압력/시간, 챔버 온도/습도 등
- **Y (출력)**: 불량 유형 (기포, Crack, Misalignment, Broken, Dirty, 이물 등)

## 목표
- 빈도 1순위 불량 기반 분류 모델 개발
- 주요 Feature 추출
- 성능 지표: **Accuracy**, **F1-score**

## 주요 단계
1. **데이터 전처리** - 결측치, 이상치, 중복 데이터, 불균형, 스케일링/정규화
2. **모델 학습** - 분류 모델 학습 및 주요 Feature 추출
3. **성능 향상** - 앙상블, 교차검증, 하이퍼파라미터 튜닝, 파생변수 생성
